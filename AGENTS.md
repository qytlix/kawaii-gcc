# Kawaii-gcc — Agent Guide

A GNU Gettext `.po` patchset that makes GCC error messages "kawaii." No runtime code—only data transformation.

## Build & Test

```bash
make              # compiles zh_CN-kawaii.po → build/zh_CN-kawaii.mo (needs gettext: apt install gettext)
make clean        # removes build/
cd test && ./test.sh   # functional test: compiles buggy C/C++ with locale overrides
```

Test requires: (1) kawaii `.mo` deployed to system locale path, (2) `LC_ALL=zh_CN.UTF-8`.

## Architecture

```
src/zh-origin.po             ── msgfmt ──→ build/zh_CN-kawaii.mo
src/zh_CN-kawaii.po          ── msgfmt ──→ build/zh_CN-kawaii.mo  (standalone full catalog)
src/zh_CN-kawaii-patch.po    ── (patch only, for review & manual merge)
```

- **`zh_CN-kawaii.po`**: complete translation catalog for direct `msgfmt` (generated by merging kawaii patch onto origin).
- **`zh_CN-kawaii-patch.po`**: only kawaii-modified `msgstr` entries; can be merged atop origin via `msgcat`.
- **`zh-origin.po`**: original GCC zh_CN translation from GNU.

## CI

`.github/workflows/test.yml` — **every push** triggers: `install gettext → make → auto-tag → GitHub Release` with `build/*` artifacts. No separate test job.

## Current GCC target

**GCC 16.1.0** (`Project-Id-Version: gcc 16.1.0`).

## Migration to new GCC version

```bash
# 1. Get original .po from GCC GitHub mirror
curl -sL "https://raw.githubusercontent.com/gcc-mirror/gcc/refs/tags/releases/gcc-<VERSION>/gcc/po/zh_CN.po" -o src/zh-origin-<VERSION>.po

# 2. Merge existing kawaii translations, keep only exact matches (no fuzzy)
msgmerge --no-wrap -o /tmp/zh_CN-kawaii-merged.po src/zh_CN-kawaii.po src/zh-origin-<VERSION>.po
# Then filter out fuzzy entries (see migration script)

# 3. Replace files, update Project-Id-Version in header
# 4. make clean && make
```

Update: `src/*.po`, `README.md`, `README-zh.md`, `.github/workflows/test.yml`.

## Style

- Kawaii register: Chinese translations use "喵~" (meow), "笨蛋" (idiot), "长点心吧喂！！!" (pay attention). All `msgstr` overrides.
- No linter, formatter, typechecker, or codegen config exists.
